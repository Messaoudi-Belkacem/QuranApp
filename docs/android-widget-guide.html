Android · Kotlin · Jetpack Glance

Building Android Widgets in 2025

The modern approach using Glance — Jetpack's Compose-based API for App Widgets on Android 5+.

00
How It Works
Android widgets still run in a RemoteViews context (they live in the launcher process), but Glance lets you write them with a Compose-like DSL and handles the RemoteViews translation automatically.
GlanceAppWidget
Composable Content
Glance → RemoteViews
Launcher renders
Key libraries: androidx.glance:glance-appwidget (stable since 1.0) + glance-material3 for theming.
01
Add Dependencies

Add Glance to your libs.versions.toml and module build.gradle.kts.

# libs.versions.toml
[versions]
glance = "1.1.1"

[libraries]
glance-appwidget = { group = "androidx.glance", name = "glance-appwidget", version.ref = "glance" }
glance-material3 = { group = "androidx.glance", name = "glance-material3", version.ref = "glance" }
// build.gradle.kts (app)
dependencies {
    implementation(libs.glance.appwidget)
    implementation(libs.glance.material3)
}
02
Define Widget Metadata

Create an XML provider info file that declares the widget's size, update period, and preview.

<!-- res/xml/my_widget_info.xml -->
<appwidget-provider
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:minWidth="250dp"
    android:minHeight="110dp"
    android:targetCellWidth="3"
    android:targetCellHeight="2"
    android:updatePeriodMillis="1800000"
    android:resizeMode="horizontal|vertical"
    android:widgetCategory="home_screen"
    android:description="@string/widget_description"
    android:previewLayout="@layout/glance_default_loading_layout" />
Android 12+: Use targetCellWidth/Height (grid cells) alongside minWidth/Height for precise sizing on modern launchers.
03
Register in AndroidManifest

Expose the widget receiver so the launcher can discover and bind it.

<!-- AndroidManifest.xml -->
<receiver
    android:name=".MyWidgetReceiver"
    android:exported="true">
    <intent-filter>
        <action android:name="android.appwidget.action.APPWIDGET_UPDATE" />
    </intent-filter>
    <meta-data
        android:name="android.appwidget.provider"
        android:resource="@xml/my_widget_info" />
</receiver>
04
Create the Widget Receiver

The receiver bridges the Android widget system with your Glance widget class.

class MyWidgetReceiver : GlanceAppWidgetReceiver() {
    override val glanceAppWidget: GlanceAppWidget = MyWidget()
}
05
Build the Widget UI

Extend GlanceAppWidget and implement Content() — a Composable using Glance's restricted UI primitives (Box, Column, Row, Text, Image, Button, LazyColumn). 

class MyWidget : GlanceAppWidget() {

    @Composable
    override fun Content() {
        // GlanceTheme applies Material 3 dynamic color to widgets
        GlanceTheme {
            MyWidgetContent()
        }
    }
}

@Composable
private fun MyWidgetContent() {
    val context = LocalContext.current
    val count by currentState(key = intPreferencesKey("count"), defaultValue = 0)

    Column(
        modifier = GlanceModifier
            .fillMaxSize()
            .background(GlanceTheme.colors.widgetBackground)
            .padding(16.dp)
            .cornerRadius(16.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Text(
            text = "Taps: $count",
            style = TextStyle(
                color = GlanceTheme.colors.onSurface,
                fontSize = 24.sp,
                fontWeight = FontWeight.Bold
            )
        )
        Spacer(modifier = GlanceModifier.height(8.dp))
        Button(
            text = "Tap me",
            onClick = actionRunCallback<IncrementAction>()
        )
    }
}
Note: Glance uses its own GlanceModifier, not Compose's Modifier. The APIs look similar but aren't interchangeable. Layouts are also a subset — no LazyRow, no Canvas, etc.
06
Handle Actions

Widget interactions go through ActionCallback. Use GlanceStateDefinition + DataStore for persistent state. 

class IncrementAction : ActionCallback {
    override suspend fun onAction(
        context: Context,
        glanceId: GlanceId,
        parameters: ActionParameters
    ) {
        // Update DataStore state, then re-render widget
        updateAppWidgetState(context, glanceId) { prefs ->
            val key = intPreferencesKey("count")
            prefs[key] = (prefs[key] ?: 0) + 1
        }
        MyWidget().update(context, glanceId)
    }
}
Other action types: actionStartActivity<MyActivity>(), actionSendBroadcast(), actionStartService() — all available as lambdas in onClick.
07
Trigger Updates from Your App

Push fresh data to all instances of your widget from a ViewModel, WorkManager job, or anywhere with a Context.

// From a ViewModel, repository, or Worker:
suspend fun refreshAllWidgets(context: Context) {
    MyWidget().updateAll(context) // updates every instance
}

// Or target a specific glanceId:
GlanceAppWidgetManager(context)
    .getGlanceIds(MyWidget::class.java)
    .forEach { id -> MyWidget().update(context, id) }
08
Size-Adaptive Layouts

Use LocalSize to render different layouts based on how large the user has resized the widget.

@Composable
override fun Content() {
    val size = LocalSize.current
    GlanceTheme {
        if (size.width >= 250.dp) {
            ExpandedLayout()
        } else {
            CompactLayout()
        }
    }
}

// Declare supported sizes in GlanceAppWidget subclass:
override val sizeMode = SizeMode.Responsive(
    setOf(
        DpSize(100.dp, 100.dp),   // small
        DpSize(250.dp, 110.dp),   // medium
        DpSize(250.dp, 220.dp)    // large
    )
)
★
Tips & Gotchas
No State Hoisting DataStore only No ViewModel in widgets Limited Composables WorkManager for bg updates
State: Don't pass state top-down like normal Compose. Use currentState() to read from DataStore Preferences inside Content(). Glance re-renders on each update() call.

Previews: Use @Preview with LocalContext mocked — Glance supports Compose previews in AS Hedgehog+.

Background updates: Use WorkManager with PeriodicWorkRequest instead of relying on updatePeriodMillis (minimum 30 min on modern Android).

Dynamic color: GlanceTheme automatically uses Material You wallpaper colors on Android 12+, falling back to your app theme on older versions.
